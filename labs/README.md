# Hands-On Labs — AI for eCommerce

**WSQ Course Code:** TGS-2026064474 · Conducted by Tertiary Infotech Academy Pte Ltd (UEN 201200696W)

All labs run on **WooCommerce** — https://woocommerce.com — and are completed across Topics 1–5 (90 minutes of practical time over 1 training day). Work through them in order; each lab builds on the one before.

Full step-by-step instructions are also in the Learner Guide. The slide deck shows each lab's purpose and outcome only.

## Demo Training Sites

Each learner is assigned ONE demo WordPress site by the trainer. Across the seven labs you build **Harbour & Co** — a small Singapore apparel and accessories retailer going online — on your site, from an empty WordPress install to a working, measured store. The sites are reset before each class.
